Promenade

GPS-verified check-in/check-out system for property managers — with real-time audit logs and admin oversight.

What is Promenade?

Promenade is a GPS-verified property attendance system. It lets administrators manage properties and property managers, while managers use the mobile app to check in and out of assigned properties. Every action is logged and reported.

User Roles

There are two roles in the system. Login automatically routes each user to the correct portal.

Admin Administrator

  • Creates and manages property manager accounts
  • Creates properties via Google Maps address search
  • Assigns multiple managers to properties
  • Views real-time sign-in/check-in audit logs
  • Exports compliance reports (CSV, Excel, PDF)
  • Resets manager passwords
  • Removes managers or properties

Manager Property Manager

  • Logs in to the mobile app using phone number and password
  • Views their assigned properties on a map
  • Checks in at a property (GPS verified)
  • Checks out when leaving (time tracked automatically)
  • Cannot access the admin web portal

Admin Web Portal — All Pages

Login at /account/signin using your phone number or email and password.

/account/signin

Sign In

Secure admin login. Enter your phone number or email and password. Non-admin users are automatically redirected to the mobile app instructions. All admin pages are protected and redirect unauthenticated visitors to this page.

/admin/dashboard

Admin Dashboard

The main command centre for administrators.

  • Stats cards: Total sign-ins, successful check-ins, failed attempts, active managers
  • Audit log table: Shows every check-in, check-out, and sign-in attempt with manager name, property, time, distance from property, and GPS status
  • Filters: Filter audit log by All / Success / Failed
  • Export: Download audit logs as CSV, Excel, or PDF with a date range picker (defaults to last 30 days)
  • Quick links: Jump directly to Assign Property or Manage Users
/admin/manage-users

Manage Property Managers

Create and manage all property manager accounts.

  • Add Manager: Enter name, phone number, and optional email. A secure temporary password is auto-generated and displayed — share it with the manager
  • Properties column: Shows all properties assigned to each manager (supports multiple)
  • Password status: Shows whether each manager has set their permanent password or is still using a temp password
  • Manage button per manager: Opens a modal with:
    • List of all assigned properties with individual remove buttons
    • Assign an existing property from the dropdown
    • Link to create and assign a new property via the map
    • Reset password (generates new temp password)
    • Delete manager (removes all associated data)
/admin/assign-property

Assign / Create Property

Create a new property using Google Maps and assign it to a manager.

  • Address search: Type an address and Google Maps auto-fills the name and exact location
  • Map click: Alternatively click anywhere on the map to set the property's GPS location
  • Property name & address: Auto-filled from the map search, editable
  • Manager dropdown: Select which manager to assign this property to
  • Multiple managers can be assigned to the same property via the Manage Users page
/account/forgot-password

Forgot Password

Request a password reset link via email. Generates a time-limited token and sends a reset email. Only available for accounts with an email address.

/setup

Initial Setup (one-time)

Used only once when setting up a new installation. Creates the first admin account and initialises all database tables. Permanently locked once an admin exists.

Manager Mobile App — Features

Property managers download and use the Expo mobile app. They log in with their phone number and password provided by the administrator.

Login Screen

Phone + Password Login

Managers log in using their phone number and the temporary password from the admin. On first login they are prompted to change their password.

My Properties

Property List

Shows all properties the manager is assigned to, loaded from the server. Multiple properties are supported — a manager can be assigned to more than one.

Check In

GPS-Verified Check In

The manager selects a property and taps Check In. The app captures their GPS coordinates and verifies they are within range of the property. The check-in is logged with timestamp, location, and status. Only one active check-in is allowed at a time.

Check Out

Timed Check Out

When the manager leaves, they tap Check Out. The system records the checkout time and automatically calculates the total time spent at the property (in hours and minutes). This duration is stored in the audit log and visible in admin reports.

Audit Logs & Reporting

Every action in the system is logged. Administrators have full visibility from the dashboard.

Audit Log

What's Tracked

  • Check-in: time, property, GPS coordinates, distance from property, status
  • Check-out: time, duration at property (hours), GPS coordinates
  • Sign-in attempts: success/failure, IP address, device info
  • Location verifications: whether manager was within range
Export

Report Export

  • Select a date range (defaults to last 30 days)
  • Export as CSV, Excel (.xlsx), or PDF
  • Reports include manager name, property, action type, time, duration, and GPS status

How It Works — End to End

A typical day in the system.

1

Admin sets up the system

Admin logs in to the web portal, creates property manager accounts, searches for property addresses via Google Maps, and assigns managers to properties.

2

Admin shares credentials

The admin copies the manager's phone number and temporary password from the success modal and shares them. The manager downloads the mobile app and logs in.

3

Manager arrives at a property

The manager opens the app, selects the property from their list, and taps Check In. The app verifies their GPS location and records the arrival time.

4

Manager leaves

When leaving, the manager taps Check Out. The system calculates the total time spent and logs it with all location data.

5

Admin reviews reports

Admin checks the dashboard to see all activity in real time. They can filter by success/failure, view GPS accuracy, and export data for payroll or compliance reporting.

Getting Started

Everything you need to get up and running.

First-time setup

Visit /setup on the web portal to create the first admin account. Enter your name, phone number, and a password (minimum 8 characters). This page locks permanently after the first admin is created.

Admin login

Visit /account/signin. Enter your phone number in the "Email or Phone" field and your password. You will be redirected to the admin dashboard.

After database setup

If you've just added new properties or ran an update, visit /api/setup once to run any pending database migrations. This is safe to call multiple times.
